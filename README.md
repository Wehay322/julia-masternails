# Анна • nail artist

Адаптивный сайт мастера маникюра и админ-панель, подключённые к Supabase.

Сайт: https://wehay322.github.io/julia-masternails/

Админ-панель: https://wehay322.github.io/julia-masternails/admin/

## Публикация

GitHub Pages: Deploy from a branch → main → /(root). В исходниках уже учтён базовый путь /julia-masternails/. Для изменения имени репозитория обновите base в трёх HTML-файлах и проверку маршрута в app.js.

## Supabase

Подключён проект manikur. config.js содержит URL и только публичный publishable key. Секретные ключи и пароли отсутствуют. Защита данных обеспечивается RLS. Посетители читают контент и отправляют заявки; владельцу нужен аккаунт, созданный вручную в Supabase, и запись в site_admins. Публичная регистрация отключена.

Как назначить владельца: setup/CONNECTED.md и setup/grant-owner.sql. Схема уже применена — повторно выполнять setup/supabase.sql не нужно.

## Редактор

Логотип, тексты, услуги, цены, фотографии, галерея, описание мастера, сертификаты, контакты, цвета и SEO редактируются из кабинета. Заявки: статусы, фильтр даты, CSV.

Фото маникюра — иллюстрации ImageGen по референсу; фото мастера — демонстрационное Unsplash. Замените демонстрационные данные реальными. Запись требует ручного подтверждения мастером и не отправляет SMS. Двухчасовые слоты по Москве: 10:00, 12:00, 14:00, 16:00, 18:00.
